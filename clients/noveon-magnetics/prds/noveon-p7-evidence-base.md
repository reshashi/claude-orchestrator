# PRD: Evidence Base & Story Engine

## 1. Executive Summary

Build the aggregate knowledge base that becomes the defensible moat. Each audit contributes anonymized data points to an aggregate picture that no one else has: a comprehensive, empirical view of how healthcare billing actually works at the transaction level across dozens of employers. This powers media strategy, policy advocacy, case studies, and market authority. Anyone can build an audit tool — no one else will have this evidence base.

## 2. Goals & Success Criteria

- [ ] **Aggregate Statistics Database** — "across X employers, Y% have billing errors in category Z"
- [ ] **Case Study Library** — anonymized stories (cancer/"Sarah", GLP-1 explosion, self-insured education)
- [ ] **Media-Ready Data Packages** — infographics, data points, white papers
- [ ] **Political Economy Foundation** — empirical evidence of systemic billing problems
- [ ] **Automatic population** from each completed audit (no manual curation)
- [ ] **Privacy-safe aggregation** — no employer or member identifiable in aggregate data

### 3.2 Database Schema

```sql
CREATE TABLE aggregate_statistics (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  metric_name TEXT NOT NULL, -- e.g., 'pct_employers_with_billing_errors'
  segment TEXT, -- e.g., 'self_insured_50_100_employees'
  value DECIMAL NOT NULL,
  sample_count INTEGER NOT NULL,
  confidence_interval_low DECIMAL,
  confidence_interval_high DECIMAL,
  as_of_date DATE DEFAULT CURRENT_DATE,
  updated_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(metric_name, segment, as_of_date)
);

CREATE TABLE case_studies (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  story_type TEXT NOT NULL, -- 'cancer', 'glp1', 'self_insured', 'billing_error'
  title TEXT NOT NULL,
  subtitle TEXT,
  anonymized_content TEXT NOT NULL,
  key_statistics JSONB DEFAULT '{}',
  source_employer_id UUID, -- internal reference, never exposed
  is_published BOOLEAN DEFAULT false,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE media_data_points (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  headline TEXT NOT NULL, -- e.g., "We audited $X million in claims and found $Y million in errors"
  supporting_data JSONB NOT NULL,
  category TEXT NOT NULL, -- 'pricing', 'billing_errors', 'pharmacy', 'access'
  is_publishable BOOLEAN DEFAULT false,
  min_sample_threshold INTEGER DEFAULT 10, -- don't publish until N employers
  current_sample_count INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT now()
);
```
