# PRD: Utilization Report Parser (B2B Ingestion Layer)

> Generated by Planner on 2026-02-13
> Project ID: noveon-p2-utilization-report-parser
> Priority: HIGH
> Phase: 2 — Get Real Data

## 1. Executive Summary

Build an automated parser for broker-provided utilization summary reports (starting with Cigna format). The existing MedicalBills.com audit engine expects EDI-835 claims files, but the first thing every employer hands you is a utilization summary PDF. This parser bridges that gap — it's the front door of the B2B product. Without it, every pilot starts with manual PDF reading that doesn't scale.

## 2. Goals & Success Criteria

- [ ] **Structured data model** for utilization report data (employer profile, financials, claimants, drugs, services)
- [ ] **Cigna PDF parser** that extracts all data points found manually in the Noveon analysis
- [ ] **Automated opportunity identification** — rules that flag patterns (GLP-1 explosion, lab steerage gaps, low engagement, catastrophic concentration)
- [ ] **Standardized audit findings format** comparable across employers
- [ ] **Client report generator** that feeds the Project 1 template automatically
- [ ] **Parser processes Noveon PDF** and produces equivalent output to manual analysis within 90% accuracy

### 3.4 Data Model: Utilization Report

```typescript
interface UtilizationReport {
  employer: EmployerProfile;
  financial: FinancialSummary;
  claimants: CatastrophicClaimant[];
  pharmacy: PharmacyAnalysis;
  services: ServiceBreakdown;
  careManagement: CareManagementStatus;
  populationHealth: PopulationProfile;
  metadata: { tpa: string; reportDate: string; periodStart: string; periodEnd: string; };
}

interface EmployerProfile {
  name: string;
  groupNumber: string;
  employeeCount: number;
  memberCount: number;
  fundingType: 'self-insured' | 'level-funded' | 'fully-insured';
  tpa: string;
  network: string;
  avgAge: number;
  demographics: { pctFemale: number; turnoverRate: number; };
}

interface AuditOpportunity {
  id: string;
  category: 'billing' | 'pharmacy' | 'steerage' | 'engagement' | 'catastrophic';
  title: string;
  description: string;
  savingsRange: { low: number; high: number; };
  confidence: 'high' | 'medium' | 'low';
  evidence: string[];
  recommendedActions: string[];
}
```
