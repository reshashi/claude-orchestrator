# PRD: Provider Price Book & Awareness Engine

> Generated by Planner on 2026-02-13

## 1. Executive Summary

Every audit secretly builds the price book. Each claim audited tells us what providers charge, how they bill, and where the pricing outliers are. This project creates the supply-side intelligence for the marketplace platform — provider pricing transparency, quality signals, and cash-pay network recruitment targets. This data doesn't exist anywhere else because no one else is looking at it at the transaction level across multiple employers.

## 2. Goals & Success Criteria

- [ ] **Provider Price Book** — what does provider X charge for procedure Y, vs Medicare, vs peers
- [ ] **Provider Quality Signals** — complication rates, readmission patterns, care fragmentation
- [ ] **Cash-Pay Network Targets** — which providers offer fair pricing and clean billing
- [ ] **Geographic pricing intelligence** — heat maps of cost variance by procedure and geography
- [ ] **Price book populates automatically** from audit findings (no manual entry)
- [ ] **Provider profiles enriched** with each successive audit

### 3.3 Database Schema

```sql
CREATE TABLE provider_prices (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  npi TEXT NOT NULL,
  provider_name TEXT,
  taxonomy TEXT,
  procedure_code TEXT NOT NULL,
  procedure_description TEXT,
  geography TEXT NOT NULL, -- CBSA or state
  billed_amount DECIMAL,
  allowed_amount DECIMAL,
  medicare_rate DECIMAL,
  ratio_to_medicare DECIMAL, -- billed/medicare
  observation_count INTEGER DEFAULT 1,
  last_observed_at TIMESTAMPTZ DEFAULT now(),
  source_audit_id UUID,
  UNIQUE(npi, procedure_code, geography)
);

CREATE TABLE provider_quality_signals (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  npi TEXT NOT NULL,
  signal_type TEXT NOT NULL, -- 'billing_pattern', 'complication_rate', 'readmission', 'fragmentation'
  signal_value DECIMAL,
  z_score DECIMAL,
  observation_count INTEGER DEFAULT 1,
  updated_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(npi, signal_type)
);

CREATE TABLE cash_pay_candidates (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  npi TEXT NOT NULL,
  specialty TEXT,
  geography TEXT,
  fair_pricing_score DECIMAL, -- 0-100
  billing_cleanliness_score DECIMAL, -- 0-100
  negotiation_track_record TEXT, -- 'cooperative', 'resistant', 'unknown'
  recommended_procedures TEXT[], -- procedures where they offer good value
  updated_at TIMESTAMPTZ DEFAULT now()
);
```
