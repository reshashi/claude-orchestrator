# PRD: Claims Learning System (Cross-Employer Intelligence)

> Generated by Planner on 2026-02-13
> Project ID: noveon-p4-claims-learning-system
> Priority: STRATEGIC
> Phase: 3 — Build the Moat

## 1. Executive Summary

Build a system where each employer audit makes the next one smarter. After auditing Noveon, we'll know things about Cigna's billing patterns, level-funded plan pitfalls, and specific provider behaviors that accelerate every subsequent Cigna-administered employer audit. This compounding knowledge is the core differentiator — no one else is doing employer-level claims audits at scale with a system designed to learn.

## 2. Goals & Success Criteria

- [ ] **Pattern Library Database** — stores findings by TPA, provider, plan design, condition, and drug
- [ ] **Benchmark Database** — statistical baselines that improve with volume (PMPM by employer size, GLP-1 penetration by industry, catastrophic claim concentration)
- [ ] **Pattern matching** — new audits auto-compare against known patterns for faster identification
- [ ] **Confidence scoring** — findings improve confidence as more data points confirm them
- [ ] **Predictive models** — given employer profile, predict most likely findings
- [ ] **Learning feedback loop** — actual recovery outcomes train better savings estimates

### 3.2 Database Schema

```sql
CREATE TABLE audit_patterns (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  category TEXT NOT NULL, -- 'tpa', 'provider', 'plan_design', 'condition', 'drug'
  subcategory TEXT NOT NULL, -- e.g., 'cigna', 'npi_12345', 'level_funded_50pct'
  pattern_key TEXT NOT NULL, -- e.g., 'glp1_explosion', 'lab_steerage_gap'
  description TEXT NOT NULL,
  frequency INTEGER DEFAULT 1, -- how many times observed
  avg_savings_low DECIMAL,
  avg_savings_high DECIMAL,
  confidence DECIMAL DEFAULT 0.5, -- 0-1 scale, improves with observations
  first_observed_at TIMESTAMPTZ DEFAULT now(),
  last_observed_at TIMESTAMPTZ DEFAULT now(),
  metadata JSONB DEFAULT '{}',
  UNIQUE(category, subcategory, pattern_key)
);

CREATE TABLE audit_benchmarks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  metric_name TEXT NOT NULL, -- e.g., 'pmpm_total', 'glp1_penetration_rate'
  segment_key TEXT NOT NULL, -- e.g., 'size_50_100_self_insured'
  sample_count INTEGER DEFAULT 1,
  mean_value DECIMAL,
  median_value DECIMAL,
  std_dev DECIMAL,
  p25 DECIMAL,
  p75 DECIMAL,
  updated_at TIMESTAMPTZ DEFAULT now(),
  UNIQUE(metric_name, segment_key)
);

CREATE TABLE recovery_outcomes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  employer_audit_id UUID REFERENCES employer_audits(id),
  finding_id TEXT NOT NULL,
  estimated_savings_low DECIMAL,
  estimated_savings_high DECIMAL,
  actual_recovery DECIMAL,
  recovery_method TEXT, -- 'negotiation', 'appeal', 'plan_change', 'steerage'
  resolution_date TIMESTAMPTZ,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);
```
