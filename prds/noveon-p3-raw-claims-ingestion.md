# PRD: Raw Claims Ingestion for Self-Insured Employers

> Generated by Planner on 2026-02-13
> Project ID: noveon-p3-raw-claims-ingestion
> Priority: HIGH
> Phase: 2 — Get Real Data

## 1. Executive Summary

Once Pat signs the consent form, Cigna must provide Noveon's actual claims data. This project builds the employer onboarding workflow (consent -> data request -> ingestion -> audit) and the Cigna-specific field mapping to feed the existing 7-layer audit engine. This is where "we analyzed your summary report" becomes "we found $73,000 in specific billing errors in your actual claims."

## 2. Goals & Success Criteria

- [ ] **Employer onboarding workflow** from consent to first audit results
- [ ] **Cigna claims data ingestion** — field mapping for Cigna-specific EDI-835 or CSV extract
- [ ] **Full 7-layer audit** runs on Noveon claims data producing actionable findings
- [ ] **Executive summary** generated for Pat with prioritized dollar-estimated recoveries
- [ ] **Action queue** of findings with recovery steps and responsible party assignments
- [ ] **End-to-end flow** completes within 48 hours of receiving claims file

### 3.4 Database Schema

```sql
CREATE TABLE employers (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  group_number TEXT,
  employee_count INTEGER,
  member_count INTEGER,
  funding_type TEXT NOT NULL, -- 'self-insured', 'level-funded', 'fully-insured'
  tpa TEXT NOT NULL, -- 'cigna', 'uhc', 'bcbs', 'aetna'
  consent_status TEXT DEFAULT 'pending', -- 'pending', 'signed', 'expired'
  consent_signed_at TIMESTAMPTZ,
  baa_status TEXT DEFAULT 'pending',
  claims_received_at TIMESTAMPTZ,
  first_audit_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE employer_audits (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  employer_id UUID REFERENCES employers(id),
  audit_type TEXT NOT NULL, -- 'utilization-summary', 'full-claims'
  status TEXT DEFAULT 'pending', -- 'pending', 'processing', 'complete', 'failed'
  claims_count INTEGER,
  findings_count INTEGER,
  total_savings_low DECIMAL,
  total_savings_high DECIMAL,
  started_at TIMESTAMPTZ,
  completed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT now()
);
```
